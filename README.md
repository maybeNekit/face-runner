# 🏃 Face Runner

**Бесконечный раннер для детей 6–10 лет, где герой бежит с лицом твоего ребёнка.**

Сфотографировал → обрезал по кружку → побежал. Лицо становится лицом персонажа,
который прыгает через спящих коров, подкатывается под летающие носки и
объезжает гигантские бутерброды.

## 🔒 Про фото — самое важное

**Фотография ребёнка никогда не покидает телефон.**

Это не обещание, а свойство архитектуры: в приложении нет ни одного сетевого
вызова. Ни `fetch`, ни `XMLHttpRequest`, ни `WebSocket`, ни аналитики, ни
крэш-репортов, ни внешних API распознавания лиц.

Фото обрабатывается локально через `<canvas>`, превращается в текстуру 256×256
и лежит в локальном хранилище устройства. Удалить его можно кнопкой в меню.

Проверить легко: включите авиарежим — игра работает полностью.

## 🎮 Как играть

| Действие | Жест | Клавиатура |
|---|---|---|
| Сменить дорожку | свайп вбок или тап по половине экрана | ← → или A D |
| Прыжок | свайп вверх | ↑ W пробел |
| Подкат | свайп вниз | ↓ S |
| Пауза | системная «назад» | — |

**Первые 11 секунд препятствий нет** — только звёздочки, чтобы освоиться.
До 26-й секунды перекрыта максимум одна дорожка из трёх. Скорость растёт
плавно и упирается в потолок.

### Что есть в игре

- **Четыре мира**, сменяются каждые 300 м: лес → космос → подводный мир → страна конфет
- **Бонусы на 8 секунд**: огромная голова, крошка, желе, реактивные ботинки, зеркало
- **Комментатор** хвалит каждые 100 метров
- **Рекорд** сохраняется, и на трассе появляется арка «ТВОЙ РЕКОРД» — обгони себя
- **Пасхалка** на 500 метрах
- Персонаж корчит рожи и издаёт нелепые звуки прямо на бегу

## 📱 Установка

1. Откройте [страницу релизов](https://github.com/maybeNekit/face-runner/releases/latest) **с телефона**
2. Скачайте `FaceRunner-v1.0.apk`
3. Откройте скачанный файл
4. Android спросит разрешение ставить приложения из этого источника — разрешите, это разово
5. Установите и запустите

APK подписан отладочным ключом. Play Store не нужен.

## 🛠 Как пересобрать

### Что понадобится

- **Node.js 22+** — Capacitor 8 требует именно эту версию
- **JDK 21** — `capacitor-android` компилируется с `sourceCompatibility VERSION_21`,
  на JDK 17 сборка падает с `invalid source release: 21`
- **Android SDK** с platform 36 и build-tools 36

### Разработка

```bash
npm install
npm run dev          # игра на http://localhost:5173
```

В dev-режиме в углу экрана виден счётчик FPS и draw calls.

### Сборка APK

```bash
npm run build        # tsc + vite
npx cap sync android
cd android && ./gradlew assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`

> **Если сборка падает с `invalid source release: 21`** — в вашем
> `~/.gradle/gradle.properties` глобально задан `org.gradle.java.home` со
> старым JDK. Он перебивает `JAVA_HOME`. Перебейте его обратно:
> ```bash
> ./gradlew assembleDebug -Dorg.gradle.java.home=/path/to/jdk-21
> ```

### Иконка и splash

Рисуются кодом, а не в редакторе:

```bash
node tools/make-assets.mjs      # SVG → PNG-исходники в assets/
npx capacitor-assets generate --android   # все плотности экрана
```

### Релиз

Пуш в `main` запускает [GitHub Actions](.github/workflows/android.yml):
сборка APK и публикация в Releases с тегом `build-<номер>`.

## 🏗 Как это устроено

```
src/
├── main.ts              роутер экранов, системная «назад», аварийный экран
├── face/                съёмка, обрезка по кругу, хранение лица
├── screens/             welcome → crop → menu → game
├── ui/                  иконки (SVG в коде), звук, вибрация, настройки
└── game/
    ├── config.ts        ВСЕ константы ощущения игры одним файлом
    ├── game.ts          оркестратор: цикл, камера, столкновения, счёт
    ├── player.ts        персонаж, гримасы, модификаторы, 4 вида смерти
    ├── obstacles.ts     пул препятствий и коллизии
    ├── obstacle-shapes.ts  банан, корова, носки, бутерброд
    ├── biomes.ts        четыре мира и их палитры
    ├── geometry.ts      склейка примитивов в одну геометрию
    └── ...              монетки, бонусы, эффекты, звук, вибрация
```

### Правила, по которым это писалось

**Только код, никаких скачанных ассетов.** Вся геометрия собирается из
примитивов, текстуры рисуются в `<canvas>`, весь звук синтезируется WebAudio,
шрифты системные. Единственные картинки в репозитории — иконка приложения,
и та сгенерирована скриптом. Игра целиком весит меньше мегабайта.

**60 FPS на среднем Android.** Бюджет — 300 draw calls, по факту тратится
**28–31**. Тени выключены, материалы Lambert без PBR. Всё живёт в пулах,
в игровом цикле не создаётся ни одного объекта: скретч-векторы заведены
заранее, состояние лежит в типизированных массивах.

**Мир едет на игрока, а не наоборот.** Персонаж стоит в `z = 0`, объекты
приезжают к нему. Иначе через пару минут забега координаты уходят в тысячи
метров и всплывает потеря точности `float`.

**Сложность считается во времени, а не в метрах.** Промежуток до следующего
препятствия равен `скорость × время_на_реакцию`. Если считать в метрах, на
разгоне препятствия начинают прилетать внезапно.

**Игра прощает.** Буфер ввода 0.18 с, хитбокс на 11% меньше модели, свайп
срабатывает в момент жеста, а не по отпусканию пальца, свайп вниз в воздухе
роняет персонажа вниз. Проход между препятствиями существует всегда.
